Для проверки использованы ранее установленные зависимости тех же версий
TypeScript/typescript-eslint/Vitest/Vite и приложенная версия Prettier.
Новая полная npm ci по присланному lockfile в контрольной среде не проводилась.
Для Rollup использовался совместимый WASM-загрузчик контрольной среды;
изменения node_modules в архив не включены. Windows и GitHub Actions
используют обычную установку зависимостей по lockfile.

Остаётся предупреждение Browserslist при сборке. Уязвимости зависимостей
на этом этапе не исправлялись. На Windows ранее было предупреждение
совместимости TypeScript и typescript-eslint: его нужно проверить снова
и учесть на шаге аудита, а не скрывать отключением предупреждений.

Исправления: раздельные AuthContext/useAuth/AuthProvider, обновлённые импорты,
удаление ненужных параметров mock, форматирование, уточнение расположения
конфигураций и статуса CI. Правила ESLint не отключались.

Команды повторения — в APPLY_CHANGES.md. Полное выполнение шага 1 требует
ещё успешного GitHub Actions, автоматического deploy и тестового коммита.
