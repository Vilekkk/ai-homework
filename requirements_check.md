## Что остаётся уточнить при строгом чтении

В списке IDE/CLI указаны Cursor, GitHub Copilot, Cline, Claude Code, Gemini CLI,
Aider и Codex. GigaCode в этом списке отсутствует, хотя упомянут в теме занятия.
В инструкции настройки названы Cursor или VS Code с плагинами; фактически
использована GigaIDE. Допустимость такого выбранного инструмента нельзя
подтвердить по тексту задания. Нужен ответ преподавателя, допускает ли он
GigaCode/GigaIDE как основной агент. Если допускает, подтверждённая практика
сохранена. Если нет, выбранный инструмент и практический шаг нужно выполнить
в одном из перечисленных вариантов, затем обновить отчёт по факту.

Файл требует сравнения минимум четырёх инструментов, но практическую задачу
и настройку явно требует для выбранного. Поэтому отсутствие четырёх отдельных
практических прогонов само по себе не объявляется невыполненным пунктом.
Документальная оценка Cursor/Cline обозначена прямо, качество кода и время
не выданы за измерения.

Отчёт не гарантирует статус «Принято»: решение о допустимости выбранного
инструмента остаётся у преподавателя. Перенос на PostgreSQL не закрывает этот
вопрос и не является обязательным шагом ДЗ 1.
