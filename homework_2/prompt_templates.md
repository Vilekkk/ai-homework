# Пять шаблонов RTCF

Инструмент практики: GigaCode в GigaIDE. Перед работой прикрепить rules.md.
Каждый шаблон содержит Role, Task, Context, Format.
Примеры ниже — библиотека готовых запросов. Не все пять примеров запускались
отдельно: фактически выполненная цепочка приведена в prompt_methodology.md.

## 1. Генерация

```text
Role: Ты Python backend-разработчик.
Task: Реализуй {функцию} по {требованиям}.
Context: Прилагаю {код}. Соблюдай rules.md. Учти {границы и совместимость}.
Format: Созданный файл, полный код, пример вызова; статус тестов без выдуманных запусков.
```

Пример использования:

```text
Role: Ты Python backend-разработчик.
Task: Создай hw2_examples/task_filter.py: completed и priority low/medium/high, offset >= 0, limit > 0 или None; сначала фильтрация, затем пагинация; исходные данные не менять. Все параметры после списка именованные. Неправильные priority и offset/limit вызывают ValueError, bool/строки/дроби для offset/limit отклоняются. Тесты пока не создавай.
Context: Проект task_api; отдельные учебные файлы hw2_examples. Применяй rules.md. Существующий API и базу не изменяй.
Format: Созданный файл, полный код, пример вызова; статус тестов без выдуманных запусков.
```

## 2. Рефакторинг

```text
Role: Ты Python-разработчик.
Task: Упрости {фрагмент} без изменения поведения.
Context: Прилагаю {реализацию и тесты}. Сохрани {контракт}; соблюдай rules.md.
Format: Минимальный патч, объяснение и результат регрессионной проверки.
```

Пример использования:

```text
Role: Ты Python-разработчик.
Task: Упрости условия фильтрации в hw2_examples/task_filter.py до прямой проверки отсутствующего фильтра или совпадения поля. Сохрани именованные аргументы, ValueError, копирование словарей и порядок пагинации. Запусти существующие 35 тестовых сценариев, сообщи фактический итог.
Context: Проект task_api; отдельные учебные файлы hw2_examples. Применяй rules.md. Существующий API и базу не изменяй.
Format: Минимальный патч, объяснение и результат регрессионной проверки.
```

## 3. Тесты

```text
Role: Ты Python-разработчик, использующий pytest.
Task: Создай тесты для {функции} и запусти их.
Context: Прилагаю {функцию и контракт}. Для данных в памяти база не нужна. Соблюдай rules.md.
Format: Файл тестов, сценарии, точная команда и настоящий вывод pytest.
```

Пример использования:

```text
Role: Ты Python-разработчик, использующий pytest.
Task: Создай hw2_examples/test_task_filter.py. Проверь оба значения completed, все приоритеты, их сочетания, отсутствие фильтров, offset/limit, пагинацию после фильтрации, пустые данные, неверные значения и типы, сохранность источника через deepcopy. Реально запусти python -m pytest test_task_filter.py -v из каталога файла.
Context: Проект task_api; отдельные учебные файлы hw2_examples. Применяй rules.md. Существующий API и базу не изменяй.
Format: Файл тестов, сценарии, точная команда и настоящий вывод pytest.
```

## 4. Исправление ошибки

```text
Role: Ты Разработчик, знакомый с Windows PowerShell.
Task: Исправь {воспроизводимую ошибку} минимальным изменением.
Context: Окружение: {ОС и оболочка}. Команда: {команда}. Лог: {ошибка}. Применяй rules.md.
Format: Причина, исправленная команда или код, настоящий результат повторного запуска.
```

Пример использования:

```text
Role: Ты Разработчик, знакомый с Windows PowerShell.
Task: Первый запуск cd "путь/hw2_examples" && python -m pytest test_task_filter.py -v остановился: PowerShell не поддерживает && в этой версии. Перейди в каталог отдельной командой, затем запусти python -m pytest test_task_filter.py -v. Не изменяй реализацию ради ошибки оболочки; покажи вывод.
Context: Проект task_api; отдельные учебные файлы hw2_examples. Применяй rules.md. Существующий API и базу не изменяй.
Format: Причина, исправленная команда или код, настоящий результат повторного запуска.
```

## 5. Декомпозиция

```text
Role: Ты Архитектор небольшого Python-проекта.
Task: Разбей {задачу} минимум на три последовательных этапа.
Context: Прилагаю {код и требования}. Соблюдай rules.md; сохраняй {контракт}.
Format: План, отдельные запросы этапов, результаты и критерии проверки; пока без реализации.
```

Пример использования:

```text
Role: Ты Архитектор небольшого Python-проекта.
Task: Спланируй функцию фильтрации и пагинации списка словарей задач. completed необязателен, priority low/medium/high или None, offset по умолчанию 0, limit None. Исходные данные не меняются. Сначала фильтрация, затем пагинация. Этапы: план, файл функции, тесты с реальным запуском.
Context: Проект task_api; отдельные учебные файлы hw2_examples. Применяй rules.md. Существующий API и базу не изменяй.
Format: План, отдельные запросы этапов, результаты и критерии проверки; пока без реализации.
```
