# Мои задачи — ДЗ 4

Локальное веб-приложение управления задачами по корпоративной UI-концепции
из ДЗ 3. Интерфейс создан в Bolt, доработан с GigaCode. Стек: React 18, TypeScript, Vite 5, Tailwind CSS 3.

## Возможности

- Создание задачи с названием, описанием и приоритетом low/medium/high.
- Смена статуса: активная / выполненная.
- Совместные фильтры статуса и приоритета, сброс и общие счётчики.
- Таблица на компьютере и карточки при ширине менее 768 px.
- Сохранение в localStorage; восстановление в том числе пустого списка.
- Валидация названия (после trim 1–200 символов), описания (до 2000).
- Удаление после подтверждения; предупреждение об ошибках хранения.

Данные находятся в браузере. Сервер, PostgreSQL и авторизация не подключены.
Шесть демонстрационных задач загружаются только при отсутствии сохранения.
При повреждённом сохранении приложение показывает предупреждение и не
перезаписывает его без явного подтверждения. До разрешения сохранения
изменения доступны только в текущем сеансе.

## Локальный запуск

Нужны Node.js и npm. Практический запуск на Windows выполнен с Node.js 24;
версия контрольного окружения указана в `verification.md`.

Откройте терминал в папке, содержащей `package.json`:

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).
Остановка сервера — Ctrl+C. Vite автоматически обновляет страницу после
изменения исходников. Для одностраничного приложения отдельный роутер не нужен.

В PowerShell при ограничении запуска скриптов можно использовать `npm.cmd`
вместо `npm`. В проекте нет жёстко заданного пути к оболочке Windows.

## Проверки и сборка

```bash
npm run typecheck
npm run lint
npm run test:run
npm run build
npm run preview
```

`npm run test` запускает интерактивный режим Vitest;
`npm run test:run` выполняет один прогон. Сборка создаёт `dist/`.
Публикация на хостинге для задания не обязательна — приведены инструкции
локального запуска.

## Структура

- `src/App.tsx` — сборка экрана, фильтры, счётчики и уведомления.
- `src/components/` — форма, фильтры, список, задача и статистика.
- `src/hooks/useTasks.ts` — операции над задачами и работа с localStorage.
- `src/types.ts`, `src/demoData.ts` — типы и демонстрационные данные.
- `src/__tests__/` — автоматические проверки компонентов, состояния и сценариев.
- [development_report.md](development_report.md) — процесс, промпты и скриншоты.
- [verification.md](verification.md) — результаты финальных проверок.
- [frontend_rules.md](frontend_rules.md) — правила для frontend-доработки.
- `requirements/` — описание, выбранная концепция, истории и ТЗ из ДЗ 3.

## Проверка вручную

1. Создать задачу с высоким приоритетом, перезагрузить страницу и найти её.
2. Совместить «Активные» и «Высокий», затем сбросить фильтры.
3. Завершить задачу и проверить счётчики; удалить задачу с подтверждением.
4. Отправить пустое название, название из 201 символа и описание из 2001 символа:
   форма должна остаться открытой и показать ошибку.
5. В DevTools проверить ширины 360, 768 и 1280 px, открытие формы и клавиатуру.
